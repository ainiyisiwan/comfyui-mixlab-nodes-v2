# ComfyUI MixLab Nodes V2

A modern, fully-compatible rewrite of [comfyui-mixlab-nodes](https://github.com/MixLabPro/comfyui-mixlab-nodes) that works with **ComfyUI v0.21.0+** and the latest frontend architecture.

> ⚠️ The original MixLab plugin has a [known bug](https://github.com/MixLabPro/comfyui-mixlab-nodes/issues) where drag-and-drop of images and workflows stopped working after ComfyUI v0.21.0. This V2 version fixes all compatibility issues.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🖱️ **Drag & Drop Images** | Drop images directly onto `Load Image From Path` nodes or the canvas |
| 📋 **Drag & Drop Workflows** | Drop PNG/WebP images with embedded workflow metadata to restore entire workflows |
| 📂 **Batch Image Loading** | Load entire folders of images as batched tensors |
| 🔍 **Metadata Extraction** | Extract embedded ComfyUI workflow/prompt from generated images |
| 📝 **Text to Image** | Render text strings as images for prompts or watermarks |
| 🎭 **Masked Composite** | Overlay images with alpha mask blending |
| 💾 **Save + Workflow** | Save images with embedded workflow metadata for sharing |

## 📦 Installation

### Method 1: ComfyUI Manager (Recommended)
1. Open ComfyUI Manager
2. Click **Custom Nodes Manager**
3. Search for `MixLab V2` or `comfyui-mixlab-nodes-v2`
4. Click **Install**
5. Restart ComfyUI

### Method 2: Git Clone
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/YOUR_USERNAME/comfyui-mixlab-nodes-v2.git
# Restart ComfyUI
```

### Method 3: Manual Download
1. Download this repository as ZIP
2. Extract to `ComfyUI/custom_nodes/comfyui-mixlab-nodes-v2/`
3. Restart ComfyUI

## 🚀 Usage

### Drag & Drop Image to Node
1. Create a **📁 Load Image From Path (MixLab V2)** node
2. Drag any image from your file manager onto the node
3. The image path is automatically populated

### Drag & Drop Workflow from Image
1. Find any image previously generated by ComfyUI
2. Drag it onto the **canvas** (empty area)
3. The entire workflow is restored from the image metadata

### Drag & Drop JSON Workflow
1. Export any workflow as JSON from ComfyUI
2. Drag the `.json` file onto the canvas
3. Workflow loads instantly

## 🧩 Nodes Reference

### Image Loading
- **📁 Load Image From Path** - Load single image with drag-and-drop support
- **📂 Load Images To Batch** - Load directory of images as batch tensor

### Workflow Tools
- **🔍 Extract Workflow From Image** - Extract embedded JSON from generated images
- **💾 Save Image + Workflow** - Save with embedded metadata for sharing

### Image Processing
- **📝 Text To Image** - Render text as RGB image
- **🎭 Image Composite Masked** - Blend foreground onto background using mask

## 🔧 Technical Details

### Why the Original Broke
The original `comfyui-mixlab-nodes` used legacy LiteGraph APIs and direct DOM manipulation that were deprecated in ComfyUI v0.21.0. The new frontend uses:
- `ComfyExtension` registration pattern
- Standardized `onDragOver` / `onDragDrop` node callbacks
- ES Module imports (`app`, `api`, `ComfyWidgets`)
- Server-side metadata extraction fallback

### What's Fixed
| Issue | Original | V2 Fix |
|-------|----------|--------|
| Drag image to canvas | ❌ Broken | ✅ Works via `canvas.ondrop` |
| Drag image to node | ❌ Broken | ✅ Works via `node.onDragDrop` |
| Workflow from PNG | ❌ Broken | ✅ PNG tEXt chunk parsing |
| Workflow from WebP | ❌ Broken | ✅ Server-side extraction fallback |
| Frontend API | ❌ Legacy | ✅ `ComfyExtension` pattern |
